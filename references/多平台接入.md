# 多平台接入

随 v0.1.0 发布。2026-11-09 核对下列官方文档；这是接入依据，不代表本通用版已在所有客户端、账号和模式实机通过。仅阅读当前平台所需部分。

## 先识别实际能力

按 [首次启用](首次启用.md) 或 [升级任务](../升级任务.md) 核对当前产品、本机或云端位置、既有安装和项目所选方法。模型名称不等于宿主能力；在 DeepSeek 等模型上运行的 Agent，也须核对它自己的技能入口、联网、文件读写与持久化能力，不能由模型名猜路径。

方法目录包含 `SKILL.md` 及其引用，下载一个入口文件不算完整安装。只配置本次目标平台，备份放到技能发现范围外；不因另一客户端有同名安装就删除它，不自动注册账号、上架市场或更改付费方案。

界面文字以当前实际客户端为准。豆包文档正文使用小写 `skill.md` 描述入口，当前包按 Agent Skills 格式提供 `SKILL.md`；尚未实机确认其大小写要求。若导入器明确要求小写，可在导入暂存包保留一份正确名称的入口并修正引用，再验证导入；不能同时保留两份独立正文或未经验证就称兼容。

## 持久入口与更新

Codex 全局规则核对实际 `CODEX_HOME`（通常 `~/.codex`）的生效文件；同一层非空 `AGENTS.override.md` 优先于 `AGENTS.md`，项目还有自己的覆盖层。合并简短读取约定，保留其他内容，不为生效擅删覆盖文件。见[官方指令发现规则](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。其他宿主使用其实际支持的规则入口，不因文件名为 AGENTS 就声称会加载。

界面管理的安装从原条目更新；不能确认替换方式时准备好包并说明待完成步骤，不能再次导入后让旧版也运行。官方客户端提供的账户同步、市场自动升级或技能开关同步，不等于本仓库包或使用者私人资料已同步。

创作版与通用版的共存选择统一按 [首次启用](首次启用.md) 执行。它们不是同名旧新版；“更新 sanjiu-evolve-general”只更新通用版。真正重复的通用版安装才在保留本地差异和资料后按宿主方式停用或归档，不能清除另一产品。

## 分开验证，分开报告

| 状态 | 所需证据 |
| --- | --- |
| 方法可读 | 当前执行者读到本版本 SKILL 和任务所需引用 |
| 资料已保存 | 在本人授权的持久位置实际写入并读回，说明已存和缺失范围 |
| 程序已运行 | 本次确有执行返回和对应结果；不能以有工具名代替运行 |
| 接续可用 | 新上下文确实读到对应项目记录并落实到成果 |

云沙箱文件需核对寿命；仅有临时文件时准备可导出包，不称长期保存。平台缺能力时给出可完成的模式；技能文本不能自行取得权限或强制宿主每轮加载。具体包的模拟和实测范围以 [检查报告](../CHECKS.md) 为准。
