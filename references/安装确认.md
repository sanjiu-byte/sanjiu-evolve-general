# 安装后主动确认

安装、更新、用户问“装好了吗”或首次项目未自动启用时读取。AI 做检查并主动告诉使用者能否开始，不要求对方理解技能目录或测试数量。

## 获取完整包

优先使用已提供的完整包；只有安装说明 MD 不等于已有方法包。国内环境先实际尝试 Gitee，失败再用 GitHub；其他环境可先用已验证可访问的一端。每个来源一次有时限的尝试，区分超时、404、登录页和损坏包，不反复等待。

- Gitee：https://gitee.com/the-third-nine/sanjiu-evolve-general
- Gitee 完整包：https://gitee.com/the-third-nine/sanjiu-evolve-general/repository/archive/main.zip
- Gitee Git 地址：https://gitee.com/the-third-nine/sanjiu-evolve-general.git
- GitHub：https://github.com/sanjiu-byte/sanjiu-evolve-general
- GitHub 完整包：https://github.com/sanjiu-byte/sanjiu-evolve-general/archive/refs/heads/main.zip

网址可打开不代表下载成功：实际解压、核对产品、VERSION 和引用文件；HTML 登录页、验证码或错误页不是 ZIP。不由国别推断 GitHub 一定不能用，也不保证所有豆包环境都能下载 Gitee。两端均失败且没有完整包时，只给用户一个动作：“请把发送方提供的完整离线 ZIP 发到这里。”不能从安装 MD 重造缺失正文。离线包按实际版本报告，不自动称为最新版；镜像不同步时核对发布版本，不覆盖已安装较新版。

`PACKAGE.json` 用于完整性比对，不是来源签名；先核对完整包确实来自上述发布源。安装内存在个人定制导致差异时保留原件，说明差异，不能为了检查通过直接覆盖用户内容。

Gitee 的 ZIP 下载可能要求登录。ZIP 请求拿到网页时，当前环境若有 Git，先用上述 HTTPS Git 地址下载完整仓库到独立暂存目录；核对内容后再安装，不复制 .git 或缓存到技能目录。没有 Git 再尝试 GitHub，仍不通就使用发送方给的完整离线包。不要让新手自己判断 HTML 是否是安装包。

## 三项分别核验

1. 文件安装：读实际安装的 VERSION、SKILL 和必需引用。有 Python 时运行 `scripts/verify_installation.py --source <可信完整包解压目录> --installed <实际安装目录>`，两个位置必须独立。无 Python 则逐项读取并比较源包与安装文件哈希，注明手动核验。没有源包不能冒称比对通过。不能把 CHECKS.md 的历史测试数字复制成这次结果。
2. 当前启用：核对宿主实际支持的发现/导入入口和启用状态，实际读取方法。仅写入猜测目录不算注册成功。完成下方虚构小任务。没有宿主入口证据时，说明当前聊天可以手动使用、自动启用尚待核实。
3. 保存就绪：在本人已授权的持久位置写入并读回“安装回执.md”，记录版本、来源、实际安装位置、本次检查结果、保存位置、未验证项和下一步。回执是配置记录，不是业务语料。无授权或只读时在回答中提供回执并标未落盘。临时沙箱不能报长期保存。既有资料、定制、“不记”和权限设置照旧保留。

虚构小任务（标明自检，不存成真实偏好）：将“这是一则内部测试通知：申请截止时间是周五15:00，请于截止前提交材料。”改短，保留截止时间和提交动作，禁止新增条件。检查实际输出仍有这两项；此项只验证当前要求落实，不证明长上下文、跨聊天或真实提效。

能在获授权的隔离新上下文中测试，才检查不用重贴正文是否发现同一安装。没有条件就标“新聊天自动启用：待验证”，不能假装已测，也不让员工跑技术测试。

## 主动回执

开始时一句：“我来安装并检查，完成后会明确告诉你是否可以开始；需要你点按钮时只给必要一步。”受阻立即反馈，获准后继续。结束时主动报告，详细证据保存在回执，回答通常只需：

```text
现在可以在这次聊天直接开始项目。（仅实际可用时这样写）
安装：通用版 v<实际版本>，文件检查通过。
资料：保存在 <本人位置>；目前仅保存安装回执，业务资料待首次项目。
新聊天：<已实测自动启用 / 尚未验证及必要的一步>。
```

未完成则第一句改为：“还没有装好，卡在 <实际原因>。你只需 <一个明确动作>，我再继续检查。”能当前使用但没有持久安装时写“当前聊天可用，长期安装尚未完成”。权限拒绝、导入失败、未加载、无法保存分别处理，不统一要求“始终访问”或 Full access。

完成后自然引导：“直接告诉我要做什么，或把项目资料发来就可以。”没有必要动作就不再要求确认。换工具/电脑/账号需重新核对新环境；豆包装好不表示 Codex 也已装好，同一 MD 可用于另一个环境，个人资料迁移另按授权处理。

首次真实任务核对项目选择并用一句话说明已采用通用版及保存位置。之后正常工作不重复播报安装；发现未加载或保存失败主动说明。这是当前对话内反馈，不启动后台通知或自动联系发送方。
