# sanjiu-evolve-general · 三九进化通用版

版本：0.1.2。

下载来源：[Gitee](https://gitee.com/the-third-nine/sanjiu-evolve-general) · [GitHub](https://github.com/sanjiu-byte/sanjiu-evolve-general)。实际可用性取决于当前网络及宿主能力。

让 AI 从你的真实需求、每次调整和判断理由中积累经验，保存可追溯资料，在后续项目中用起来。可以用于代码、文档、设计、运营及其他持续项目；起步不预装三九的脚本创作偏好。

## 直接发给 AI

把收到的完整 ZIP 直接发给平时工作的 AI。等它告诉你“现在可以开始项目”，就发需求或项目资料。需要授权或手动导入时，按它给出的那一步操作。

还没有包时可取 [GitHub 版本 ZIP](https://github.com/sanjiu-byte/sanjiu-evolve-general/archive/refs/tags/v0.1.2.zip) 或 [Gitee 版本 ZIP](https://gitee.com/the-third-nine/sanjiu-evolve-general/repository/archive/v0.1.2.zip)。Gitee 下载可能需要登录。

给收到安装包的 AI：用户交付此包用于安装或更新时，请找到与本 README 同目录的 [安装说明](安装.md)，直接使用包内文件完成安装和自检。已有安装按 [升级任务](升级任务.md) 原位更新。

## 它如何进化

| 实际发生的事 | AI 应完成的动作 | 为什么 |
| --- | --- | --- |
| 开始任务 | 找到该项目的目标、边界、原材料和适用经验 | 避免把别人的偏好或旧项目设定带进来 |
| 连续修改 | 核对本次改变项与仍须保留的要求 | “简短一点”不自动取消原有信息和目标 |
| 收到反馈 | 先改成果，保留具体前后版本、理由及适用条件 | 学到判断依据，避免只记一个“不要这样” |
| 阶段结束或接续 | 保存获准的原文、成果、附件及覆盖说明 | 短摘要可以回到详细证据，原件缺失会明确标出 |
| 再遇到类似任务 | 读取相应经验并检查成果是否用上 | 写进文件不等于以后真的少重复解释 |

对错与效果按任务判断。代码可以核验行为和测试；创意、设计等任务要看是否更快进入使用者要的方向、是否保留其有意坚持的取舍。模拟通过不代替真实使用效果。

## 与创作版的关系

[sanjiu-evolve](https://github.com/sanjiu-byte/sanjiu-evolve) 保留三九既有创作方法。本项目保留进化流程与工具，经验随使用者及项目积累。两个产品各自安装和更新；更新通用版不会覆盖创作版。

同一任务指定一个进化方法，专业技能按需配合。已有项目不会仅因安装通用版就被改入口；明确切换时保留原资料和适用经验，不重复记录。使用者自己的资料属于使用者，完整聊天不会自动回传作者。
