# 验证方法

`test_edit_guard.py` 检查局部修改工具的确定性行为：范围外字节、输入变化、重复片段、已有输出、错误输入及文件状态等。测试只使用虚构材料，可用 `python -m unittest discover -s tests -p test_edit_guard.py` 运行；设置 `SANJIU_TEST_TMPDIR` 可指定临时目录。

`scenarios.json` 是通用版行为场景与验收依据。独立执行者只获得方法、任务及必要输入，在隔离目录完成任务；审核者再对照这些依据检查实际输出与写入文件。案例文本与预期没有固定领域审美。

场景列出不等于已经跑过。实际执行范围、失败及修正见根目录 [CHECKS.md](../CHECKS.md)。模拟用于发现机制缺陷，真实使用效果仍需使用者后续项目反馈。
